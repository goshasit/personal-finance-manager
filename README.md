# Personal Finance Manager

Консольное приложение на Java для управления личными финансами. Позволяет учитывать доходы и расходы, управлять категориями и бюджетами, контролировать финансовые лимиты, просматривать статистику и сохранять данные между запусками.

Проект разработан с использованием Java 21, Maven, Gson и JUnit 5.

## Возможности

### Управление пользователями
- Регистрация новых пользователей.
- Авторизация с использованием пароля.
- Хранение паролей в виде BCrypt-хешей.

### Управление финансами
- Добавление доходов и расходов.
- Редактирование и удаление финансовых операций.
- Привязка операций к категориям.
- Фильтрация операций по датам и категориям.
- Просмотр финансовой статистики.
- Расчёт общих сумм доходов и расходов.

### Категории
- Создание категорий доходов и расходов.
- Просмотр списка категорий.
- Переименование категорий.
- Удаление категорий.
- Проверка использования категории перед удалением.

### Бюджеты
- Создание бюджетов для категорий.
- Просмотр существующих бюджетов.
- Изменение бюджетных лимитов.
- Контроль оставшихся средств.
- Уведомления при достижении 80% бюджета, исчерпании лимита и его превышении.

### Импорт и экспорт
- Экспорт финансовых операций в CSV.
- Импорт операций из CSV.
- Экспорт данных в JSON.
- Импорт данных из JSON.

## Требования

Перед запуском необходимо установить:

- **JDK 21** или новее.
- **Apache Maven 3.8** или новее.
- **Git** — для клонирования репозитория.

Проверить установку Java и Maven можно командами:

```bash
java -version
mvn -version
git --version
```

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone git@github.com:goshasit/personal-finance-manager.git
```

Перейдите в папку проекта:

```bash
cd personal-finance-manager
```

Если SSH не настроен, можно использовать HTTPS:

```bash
git clone https://github.com/goshasit/personal-finance-manager.git
```

### 2. Сборка и запуск

Основная команда запуска:

```bash
mvn clean compile exec:java
```

Maven автоматически загрузит необходимые зависимости, скомпилирует исходный код и запустит приложение.

### 3. Запуск в Windows PowerShell

Для корректного отображения русских символов в консоли рекомендуется перед запуском выполнить:

```powershell
chcp 65001

[Console]::InputEncoding = [System.Text.UTF8Encoding]::new()
[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new()
$OutputEncoding = [System.Text.UTF8Encoding]::new()

mvn clean compile exec:java
```

### 4. Запуск из IntelliJ IDEA

1. Откройте IntelliJ IDEA.
2. Выберите **File → Open**.
3. Укажите папку проекта.
4. Дождитесь загрузки Maven-зависимостей.
5. Откройте `src/main/java/ru/finance/Main.java`.
6. Запустите метод `main()`.

## Работа с приложением

После запуска появляется меню авторизации:

```text
========== PERSONAL FINANCE MANAGER ==========

1. Регистрация
2. Вход
0. Выход

Выберите действие:
```

Для начала работы необходимо зарегистрировать пользователя или войти в существующую учётную запись.

После успешной авторизации открывается главное меню приложения.

Основные разделы:

| Раздел | Описание |
|---|---|
| Финансовые операции | Добавление, просмотр, редактирование и удаление доходов и расходов |
| Фильтрация | Поиск операций по периоду и категориям |
| Бюджеты | Создание, просмотр и изменение бюджетов |
| Статистика | Анализ доходов и расходов |
| Категории | Управление категориями доходов и расходов |
| CSV | Импорт и экспорт операций |
| JSON | Импорт и экспорт финансовых данных |

Взаимодействие с приложением осуществляется через консольное меню: пользователь выбирает номер нужного действия и вводит запрашиваемые данные.

## Хранение данных

Для сохранения информации используется JSON.

Реализация хранения отделена от бизнес-логики с помощью интерфейсов репозиториев.

Основные компоненты:

- `UserRepository` — работа с пользователями.
- `WalletRepository` — работа с финансовыми кошельками.
- `JsonUserRepository` — JSON-реализация хранения пользователей.
- `JsonWalletRepository` — JSON-реализация хранения кошельков.
- `JsonStorage` — вспомогательная логика чтения и записи JSON.

Локальные пользовательские данные и файлы экспорта не входят в Git-репозиторий.

CSV-файлы экспорта сохраняются в:

```text
data/exports/
```

### Архитектура

Проект разделён на несколько логических слоёв.

**CLI — пользовательский интерфейс**

Пакет `ru.finance.cli` отвечает за взаимодействие с пользователем, отображение меню, чтение ввода и вывод результатов.

**Core — бизнес-логика**

Содержит модели предметной области, интерфейсы репозиториев и сервисы.

- `model` — сущности пользователей, кошельков, категорий, бюджетов и операций.
- `repository` — интерфейсы доступа к данным.
- `service` — бизнес-логика авторизации и управления финансами.

**Infrastructure — инфраструктурный слой**

Содержит реализации хранения данных и вспомогательные компоненты для работы с JSON.

Такое разделение позволяет отделить бизнес-логику от конкретного способа хранения данных.

## Тестирование

Для запуска всех автоматизированных тестов выполните:

```bash
mvn clean test
```

Для запуска тестов без предварительной очистки:

```bash
mvn test
```

Тесты покрывают основные компоненты приложения:

- модели предметной области;
- управление кошельками;
- авторизацию;
- финансовые операции;
- JSON-хранение;
- работу репозиториев.

## Проверка качества кода

Для запуска Checkstyle:

```bash
mvn validate
```

Checkstyle проверяет исходный код на соответствие настроенным правилам оформления.

Конфигурация находится в:

```text
config/checkstyle.xml
```

## Непрерывная интеграция

В проекте настроен GitHub Actions.

Workflow находится в:

```text
.github/workflows/maven.yml
```

При отправке изменений в ветку `main` или `master`, а также при создании Pull Request, GitHub Actions:

1. Загружает исходный код репозитория.
2. Устанавливает JDK 21.
3. Настраивает Maven.
4. Выполняет команду:

```bash
mvn clean test
```

Это позволяет автоматически проверять работоспособность проекта при изменениях.
