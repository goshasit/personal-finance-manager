# Personal Finance Manager

Консольное приложение на Java 21 для управления личными финансами.

## Возможности

- Регистрация и авторизация пользователей.
- Просмотр баланса и финансовой статистики.
- Учёт доходов и расходов.
- Создание, просмотр, редактирование и удаление категорий.
- Редактирование и удаление финансовых операций.
- Фильтрация операций по периоду и категориям.
- Создание и редактирование бюджетов.
- Уведомления о достижении 80% бюджета, исчерпании и превышении лимита.
- Импорт и экспорт операций в CSV и JSON.
- Сохранение данных между запусками приложения.

## Технологии

- Java 21
- Maven
- Gson 2.11.0
- jBCrypt 0.4
- JUnit 5
- Maven Checkstyle Plugin
- GitHub Actions

Все зависимости подключаются автоматически через Maven. Устанавливать библиотеки вручную не требуется.

## Требования

- JDK 21 или новее.
- Apache Maven.
- Git (для клонирования репозитория).
